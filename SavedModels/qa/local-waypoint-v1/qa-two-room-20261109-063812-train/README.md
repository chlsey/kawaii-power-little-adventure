## Training and lineage

- User authorized **100 two-room episodes**, without advancing to another stage. Training uses seeds 16000-16099, exactly one completed attempt per seed; no 101st layout is generated by DummyVecEnv's terminal auto-reset.
- Full actor, critic and optimizer continuation from [QA-44](../qa-waypoint-throughput-20261108-233001-train/README.md), SHA-256 `1094cd0cea9a3fe2bc183b5bd3a7c1dc2ea6d22f4d5d5939629d7ed7ccafde8e`. Same `local-waypoint-v1`, 134 -> 64 -> 64 -> 2, previous movement/current wall and exit rays/waypoint inputs, world X/Z movement only.
- Same QA-45 dungeon-manager/generator path, game player prefab/colliders, two empty 20 x 20 rooms inside the 100 x 100 placement area, generated corridors/walls/open doors, no enemies, loot, puzzles or props. Actual exit trigger completes the task; each attempt otherwise ends after 600 actions / sixty simulated seconds. Base speed four units/s, action interval 0.1 s.
- Keep the QA-45 oracle heuristic fixed: A* on integer floor centres to the known exit, clear local instructions at most ten units away, 0.5 arrival tolerance, twenty-action no-progress replan. Its layout/exit knowledge is not supplied directly to the policy. Recovery can still fail after actor drift; no planner fix was mixed into this experiment.
- Training reward: +50 actual exit; +0.1 per new closest waypoint unit and +1 per new arrival under one shared **+5 positive attempt budget**; -0.001/action. Target changes do not refill the budget. Evaluation rewards are zero. The adapter's new `training_rewards` flag defaults false.
- Same PPO learning rate 0.0002, gamma 0.99, entropy coefficient 0.01, rollout 256, minibatch 64, CPU. No architecture/hyperparameter change. Existing timeout-as-terminal bridge behavior is unchanged.

**Training result:** 69 exits / 31 timeouts, 32,495 collected actions, mean return 38.902, successful mean 20.138 s / all-case mean 32.495 s; maximum positive waypoint reward five. Training uses exploratory sampled actions, so its 69% is not a frozen evaluation score. Final **360,928 branch steps / 14,070 optimizer updates / 4,100 actor-lineage episodes**, increments +32,495 / +1,260 / +100 from QA-44. Stopping at exactly 100 episodes discards 239 transitions in the final incomplete PPO rollout; those actions remain included in the collected-step counter. Six periodic archives plus the final model are retained.

## What changed in evaluation

Paired outcomes: **12 both succeed, 19 gained, 17 lost, 52 both fail**. Completion change +2 percentage points, exploratory 20,000-draw paired case-bootstrap 95% interval -10 to +14 points; exact paired p=0.868. Capped duration saves 1.003 s on average, interval -4.561 to +6.424 s. On the same twelve common successes, mean duration changes 11.808 -> 11.642 s. These are case-level summaries from one training trajectory, not independent-training uncertainty or evidence of a reliable gain.

Child failures end in starting room 49 / corridor 20; none enters the exit room. Failures with zero waypoint arrivals fall 33 -> 9, but overall exit completion barely changes. Near-immobile actions (<0.02 units/action) rise 6,097 -> 7,509 and actions without a usable waypoint rise 918 -> 10,651. The learned actor and fixed heuristic's recovery behavior remain coupled: better initial target reaching does not establish reliable doorway/corridor traversal. End-location labels do not prove the actor never left that region earlier.

On all original 100 empty-room full-minute target sequences (seeds 288000-288099), mean throughput is similar, 44.43 -> 44.17, and every case still reaches ten. The lower tail worsens: minimum 37 -> 11. Retain QA-44 rather than declaring the child generally better. Further training, recovery changes and deployment require a separate user-selected task; none was started.
